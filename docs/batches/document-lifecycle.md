# Document lifecycle batch

Scope: blueprint sections 6.2 and 9.6; metadata lifecycle for drafts, review, release and revisions.

1. Staff may create drafts in assigned divisions; Directors and managers may manage and release documents in scope.
2. Private object keys and SHA-256 checksums must be attached before review submission.
3. Review submission, release, revision, and withdrawal are transactional and append audited lifecycle events.
4. Revisions preserve the document identity format and increment `R` while superseding the released source.
5. Synthetic preview actions and the React document centre cover create, attach, submit, release, revise and withdraw flows.

Acceptance: PGlite allowed/denied role transitions, hash validation, revision sequencing, audit-chain verification and a Chromium walkthrough.

Status: locally implemented. R2 object upload, real private delivery acceptance, legacy migration and SharePoint filing remain external or separate work.
